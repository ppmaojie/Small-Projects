## Current projects
### AliveCheck
An experimental project created by an OpenClaw agent to explore AI workflows, inspired by the popular Chinese app 'Are You Dead Yet?' (死了么). There might still be issues with the code, but no further fixes or updates are planned since this is strictly a learning experiment for AI agents.

### 活着么
这是一个由 OpenClaw agent 创建的实验性项目，旨在探索 AI 工作流，灵感来源于中国热门应用“死了么”。该程序本身可能仍存在一些问题，但后续可能不会再进行修复或维护，因为这仅是一个用于学习 AI Agent 的实验性项目。
